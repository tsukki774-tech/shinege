# 3D キャラコンFPS v10（高視認性アリーナ＆武器インスペクト対応）

## v10 新機能
- **見やすく爽やかなステージデザイン**：
  - 昼間のスカイブルー背景＋明るいライトスレート床を採用し、対戦相手（赤・オレンジ）や弾道トレーサー、ギミックが遠距離でも一目で判別できます。
  - すべての構造物に輪郭エッジラインを追加し、中央シタデル（ホワイト＆スカイブルー）・4隅のスカイ要塞（ロイヤルブルー）・前線バンカー（ティール）・ウォールラン壁（バイオレット）を役割別に色分けしました。
- **武器・近接武器の「眺める（インスペクト）」モーション**：
  - PCでは **`V` キーまたは `T` キー**、スマホ・iPadでは **`LOOK（眺める）` ボタン**（ボタン配置編集にも対応）で、装備中のメイン銃や近接武器をカメラ前に持ち上げてスキンや造形をじっくり眺められます。
  - **カラムビット** を装備して眺めると、フィンガーリングを軸にクルッと回転する専用スピンモーションが再生されます。
  - 攻撃・リロード・武器切替を行うと即座にキャンセルされ、戦闘の邪魔になりません。
