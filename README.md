# 3D キャラコンFPS v20（リスポーン再帰バグ修正・2人/4人モード切替・撃破回復）

## v20 更新内容
1. **リスポーン時の再帰エラー（Maximum call stack size exceeded）を修正**
   - `applyCharacterStatsToPlayer(true)` 内部で自分自身を無限呼び出ししていた箇所を修正し、撃破されて3.0秒後に確実にリスポーンできるようにしました。
2. **2人モード (1v1) / 4人モード (乱戦) 切替**
   - ロビー画面の「人数」セレクトから切り替え可能。
3. **4人モード限定の撃破回復（キルリカバリー）**
   - 4人モード中に敵を倒すと HP +45 回復 ＆ 残弾全回復。
