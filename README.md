# 3D キャラコンFPS v14（キャラクター4体＆固有スキル・ワイヤー固有化対応）

## v14 新機能
- **キャラクター選択システム（4キャラクター＆固有スキル）**：
  - これまで全キャラ共通だった **ワイヤーグラップル** を **HOOK（フック）の固有スキル** へ変更し、4人のキャラクターそれぞれに固有スキルとステータス・パッシブ特性を実装しました。
  - 固有スキルは **右クリック / `F` キー**（スマホ・タブレットは右下の **スキルボタン：`WIRE` / `BOOST` / `SHIELD` / `BLINK`**）で発動します。

### キャラクター一覧
1. **HOOK（フック）** `[HP 100 / 速度 104%]`
   - **固有スキル：ワイヤーグラップル（CD 2.8s）** — 建物やタワーへワイヤーを射出して高速スイング＆スリングショット移動。
2. **BLITZ（ブリッツ）** `[HP 100 / 速度 112%]`
   - **固有スキル：オーバードライブ（CD 9.0s）** — 5秒間、移動速度・連射レート・リロード速度を超加速し、ダッシュCDを即時リセット。
   - **パッシブ**：スライディング速度ボーナス強化。
3. **VANGUARD（ヴァンガード）** `[HP 135 / 速度 96%]`
   - **固有スキル：イージスバリア（CD 10.0s）** — HPを30即時回復し、4秒間受けるダメージを75%軽減。
4. **SPECTRE（スペクター）** `[HP 95 / 速度 108%]`
   - **固有スキル：シャドウステップ（CD 7.5s）** — 視線方向へ18m瞬間ワープし、2.5秒間半透明ステルス化。
   - **パッシブ**：近接攻撃ダメージ +20（威力55 → 75）。
