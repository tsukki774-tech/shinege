# 3D キャラコンFPS v13（リロードボタン＆3D勝利演出対応）

## v13 新機能
- **画面上のリロードボタン追加**：
  - スマホ・タブレット用タッチ操作に **`RELOAD（装填）` ボタン** を追加しました（ボタン配置カスタマイズ画面で好きな位置へ移動・保存できます）。
  - さらに右下の武器HUD内にも **`R 装填` ボタン** を追加し、マウスクリック・タップでも即座にリロードできます。
- **3D空間の勝利演出（ビクトリーセレブレーション）**：
  - バトルに勝利した瞬間、カメラが勝者の周囲を旋回・上昇する **シネマティック勝利カメラ** に切り替わり、装備中の銃や近接武器を掲げて回転させる **ビクトリーポーズ** が再生されます。
  - 同時にフィールド上に **黄金の光の柱（ビクトリーピラー）** と **55個の3D花火パーティクル**、画面の紙吹雪＆勝利ファンファーレが豪華に炸裂します。
