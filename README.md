# 3D キャラコンFPS v15（縦横メガアリーナ＆最大4人対戦＆武器モデル刷新）

## v15 新機能
1. **縦にも横にも超拡張された5層スカイメガアリーナ（360×360m / 高さ最大58m）**
   - **第5層（Y=46〜54m）**：中央上空の浮遊神殿「成層圏スカイサンクチュアリ」。ハイジャンプパッドや4隅タワーからの超ロングジップラインで到達可能。
   - **第4層（Y=34〜40m）**：4隅の超高層スカイスクレイパー要塞＆高空浮島デッキ。
   - **第3層（Y=20〜30m）**：高さ24〜34mの巨大垂直ウォールランパネル＆中層リングデッキ。
   - **第2層（Y=9〜18m）**：2層構造の前線バンカー＆スカイブリッジ。
   - **第1層（Y=0〜8m）**：360×360mのグランドフロア、ハイパワージャンプパッド、スピードブースト床。
   - 右上HUDに現在の **高度（ALT）** をリアルタイム表示。

2. **最大4人フリーフォーオール対戦（オンライン最大4人 / ソロ3BOT乱戦）**
   - **オンライン対戦**：ホストが4桁コードを発行し、最大3人の友達（合計4人）が同時入室してデスマッチが可能。
   - **ソロ練習**：3体の個性派BOT（BLITZ / VANGUARD / SPECTRE）が立体マップの上下を飛び回り、プレイヤーとBOT同士でも撃ち合う4人乱戦モード。
   - 左上に **4人リアルタイム順位＆キル数・HPランキングボード** を表示。

3. **全武器3Dビューモデルのハイディテール刷新**
   - **銃器5種**：多層シュラウド・ホロサイト・マズルブレーキ・発光コア・バイポッド・マルチバレル・発光ドラムマガジンを追加。
   - **近接武器4種**：鋼鉄コア＋高出力プラズマエッジの2層構造や八角鍔・カーボンシャフトなど立体造形を大幅強化。
