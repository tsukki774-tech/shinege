# 3D キャラコン鬼ごっこ（スマホ・iPad＆PC両対応版 v3）

Three.js を使った FPS視点の3Dパルクール鬼ごっこです。
ボタン配置のカスタマイズ機能と、鬼や自分の位置がわかるミニマップを追加しました。

## 新機能（v3）
- **ボタン配置カスタマイズ**：スタート画面・一時停止画面の「ボタン配置を変更」から、`JUMP`・`SLIDE`・左スティックの基準位置をドラッグで好きな場所へ移動して保存できます。
- **ミニマップ**：画面左上にアリーナ全体・障害物・ジャンプパッド・自分の向き（視野）と鬼の位置をリアルタイム表示します。
- **左半分スティック専用**：移動スティックは画面左側だけで反応し、右側は視点操作専用になっています。

## スマホ・iPad操作
- **左画面（バーチャルスティック）**：前後左右の移動
- **右画面スワイプ**：視点移動（スティックと同時に操作可能）
- **`JUMP` ボタン**：ジャンプ / 着地即ジャンプでバニホ / ウォールラン中に壁キック
- **`SLIDE` ボタン**：長押しでスライディング加速
- **右上 `リトライ` / `停止`**：即リトライ・一時停止

## PC操作
- **移動**：`W` `A` `S` `D`
- **視点**：マウス
- **ジャンプ / 壁キック**：`Space`
- **スライディング**：`Shift` または `C`
- **即リトライ**：`R`

## GitHub Pages で公開する手順
1. GitHub リポジトリにこのZIPの中身（`index.html`, `style.css`, `game.js`, `README.md`）を直下に配置します。
2. リポジトリの **Settings** → **Pages** → **Branch** を `main`（`/ (root)`）にして **Save** を押します。
3. 発行されたURLをiPadやスマホのブラウザ（Safari / Chrome）で開けばそのまま遊べます。
