# 3D キャラコンFPS v7（友達と1v1オンライン対戦）

## 概要
スライディング・バニホ・ウォールラン・空中ダッシュ・グラップルワイヤー・ジップラインといったハイスピードなキャラコンを駆使して、友達とリアルタイムで撃ち合う3DブラウザFPSです。

## 友達と遊ぶ方法（サーバー不要・GitHub Pages対応）
1. **ホスト側**：メニューの「部屋を作る（ホスト）」→「部屋を作成して待機」を押し、表示された **4桁のルームコード** を友達に伝えます。
2. **参加側**：同じURLを開き、「部屋に入る（参加）」から4桁のコードを入力して「接続する」を押すと、即座に1v1対戦が始まります。
3. **ソロ練習**：1人のときは「ソロ練習（BOT）」のままスタートすると、移動・射撃するBOT相手に練習できます。

## ルール＆武器
- **勝利条件**：先に目標キル数（3 / 5 / 10キル）を達成したプレイヤーの勝利（HP 100・被弾撃破後3秒でリスポーン）。
- **照準オート射撃（ON/OFF切替可）**：照準が相手に重なると赤く光り自動発射されます。手動射撃（PC左クリック / スマホFIREボタン）も併用可能。
- **3種類の武器（1/2/3キー・ホイール・スマホ切替ボタン）**：
  - **パルスライフル**：18発 / 14ダメージ（連射バランス型）
  - **ショットガン**：6発 / 13ダメージ×7ペレット（近距離大火力）
  - **スナイパー**：4発 / 65ダメージ（超長距離・2発キル）
