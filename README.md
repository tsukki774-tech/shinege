# 3D キャラコン鬼ごっこ（1人用プロトタイプ）

Three.js を使った FPS視点の3Dパルクール鬼ごっこです。  
ビルド不要・外部アセット不要なので、GitHub Pages にそのままアップして遊べます。

## 実装済みのキャラコン技
1. **スライディング（`Shift` or `C`）**：走りながら押すと前方に加速し、低い姿勢でゲートをくぐれる
2. **スライドジャンプ＆バニーホップ（バニホ）**：スライディング中や高速移動中に着地即ジャンプすることで速度を維持・加速
3. **ウォールラン＆壁キック**：空中で壁（特に紫の大型パネル）に近づいて `W` を押すと壁を走り、そこから `Space` で反対側へ大きく跳べる
4. **ジャンプパッド**：黄緑のパッドを踏むと上空へ大ジャンプ
5. **スピード連動FOV**：加速するほど視野角が広がり疾走感アップ

## 操作方法
- **移動**: `W` `A` `S` `D`
- **視点**: マウス
- **ジャンプ / 壁キック**: `Space`
- **スライディング**: `Shift` または `C`
- **即リトライ**: `R`

## GitHub Pages で公開する手順
1. GitHub でリポジトリを作成し、このZIPの中身（`index.html`, `style.css`, `game.js`, `README.md`）を直下に配置します。
2. リポジトリの **Settings** → **Pages** → **Branch** を `main`（`/ (root)`）にして **Save** を押します。

## 次のステップ（友達とオンライン対戦化）
このコードでキャラコンの気持ちよさ（`game.js` 上部の `CONFIG`）を調整できたら、次は **PeerJS（WebRTC）** を組み込んで「ルームIDで友達と鬼ごっこ対戦」に拡張できます。
