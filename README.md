# 3D キャラコンFPS v19（2人/4人モード切替・4人モード撃破回復・リスポーン修正）

## v19 更新内容
1. **リスポーン不具合の完全修正**
   - 撃破されてから3.0秒後にリスポーンする際、古い変数参照（`rival`）で処理が停止していたバグを修正し、全生存敵から最も離れた安全なスポーン地点へ確実に復活するよう改善しました。
2. **「2人モード (1v1)」と「4人モード (乱戦)」の切り替え対応**
   - ロビー画面の「人数」セレクトから **2人モード（1v1タイマン）** と **4人モード（最大4人乱戦）** をいつでも切り替え可能にしました（ソロ練習・オンライン部屋の両方に対応）。
3. **4人モード限定の撃破回復（キルリカバリー）システム追加**
   - 4人モード（乱戦）中に敵を撃破すると、**HP +45 回復 ＆ マガジン全弾リロード**が即座に発動し、漁夫（サードパーティ）に対抗して連続キルを狙えます。
