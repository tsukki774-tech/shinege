# 3D キャラコンFPS v18（全武器の素モデル造形アップグレード）

## v18 更新内容
スキン未装着（スタンダード）の状態でも重厚で洗練されたシルエットになるよう、**銃5種＋近接4種＝全9武器の3Dプロップ造形**を大幅にディテールアップしました。

- **銃5種**：ピカティニーレール刻み、多層レシーバー、ホログラス/スコープのレンズ表現、放熱スリット、アングルグリップ、ドラム弾帯、電磁コイルリングなどの立体パーツを追加。
- **近接4種**：
  - **コンバットナイフ**：血抜きフラー溝・背刃セレーション・クリップポイント切っ先を追加
  - **カラムビット**：フィンガーグルーブ付き湾曲グリップ＋3段鉤爪クローブレード＋二重リング
  - **サイバーカタナ**：菱形柄巻き・八角透かし鍔・ハバキ金具・反りのある二段刀身
  - **プラズマアックス**：リアクターコア・三日月プラズマ大刃・後方アーマーピアシングスパイク
