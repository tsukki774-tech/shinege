# 3D キャラコンFPS v8（2スロット装備＆ショップ・カラムビット・スキンガチャ対応）

## v8 新機能
- **2スロットロードアウト制（メイン銃 ＋ 近接武器）**：
  - バトルに持ち込む **メイン銃（Slot 1）** と **近接武器（Slot 2）** を事前に装備し、試合中は `1` / `2` キー・マウスホイール・スマホ切替ボタンで素早く持ち替えられます。
  - **照準オート攻撃**は銃・近接武器のどちらにも自動対応します。
- **バトル報酬通貨（CR）**：
  - オンライン対戦勝利で **+100 CR**（敗北でも参加賞 +20 CR）、ソロ練習勝利で **+40 CR**（敗北 +10 CR）を獲得できます。
- **アーマリー＆ショップ**：
  - **メイン銃（5種）**：パルスライフル（初期）・ボルトSMG（110 CR）・スキャッターショットガン（150 CR）・レイルスナイパー（200 CR）・タイタンLMG（260 CR）
  - **近接武器（4種・すべて共通性能：威力55）**：コンバットナイフ（初期）・**カラムビット（160 CR）**・サイバーカタナ（220 CR）・プラズマアックス（280 CR）
- **スキンガチャ（1回 80 CR / 3連 220 CR）**：
  - `COMMON` 〜 `LEGEND（ロイヤルゴールド）` まで全7種のレアスキンが排出され、入手したスキンはメイン銃と近接武器の両方に装着できます。
