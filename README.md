# しょぼん風ミニアクション（初見殺し2Dゲーム）

HTML / CSS / JavaScript（Canvas）だけで動く、しょぼんのアクション風の死にゲー試作版です。  
外部画像・音声ファイル不要なので、GitHub Pages にそのままアップするだけで友達にURLを共有して遊んでもらえます。

## 収録している初見殺しギミック（全7種）
1. **孔明の罠（見えないブロック）** - 最初の穴の手前でジャンプすると頭をぶつける
2. **ドクロが出る「？」ブロック** - 叩くと踏んでも倒せないドクロが転がってくる
3. **踏むと落ちる床** - 立ち止まると即落下
4. **チェックポイント直後の隠しトゲ** - 安心した瞬間に地面から飛び出す
5. **落下してくる背景の雲** - 近づくと顔が変わって真下に落ちてくる
6. **2個目の見えないブロック** - ラスト手前の穴に仕掛けられた追い打ち
7. **逃げるゴールポール** - ゴール直前で右へ逃げ、元の位置からトゲが出る

## 操作方法
- **移動**: `←` `→` または `A` `D`
- **ジャンプ**: `Space` / `↑` / `W`
- **即リトライ**: `R`
- スマホ・タブレットでは画面下のタッチボタンで操作できます。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成します（例: `shobon-action`）。
2. このZIPを展開した中身（`index.html`, `style.css`, `game.js`, `README.md`）をリポジトリにアップロード（または `git push`）します。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Source** を `Deploy from a branch`、**Branch** を `main`（フォルダは `/ (root)`）にして **Save** をクリックします。
5. 1〜2分待つと公開URL（`https://あなたのID.github.io/リポジトリ名/`）が発行されます。

## 改造のヒント（`game.js`）
- **難易度調整**: `game.js` 上部の `GRAVITY`・`MOVE_SPEED`・`JUMP_FORCE` を変更すると操作感が変わります。
- **罠の追加**: `buildStage()` 関数の中の `blocks.push(...)` や `spikes.push(...)` をコピペして座標を変えるだけで、新しい初見殺しをどんどん増やせます。
