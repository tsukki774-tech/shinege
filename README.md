# 3D キャラコン鬼ごっこ v5（広大アリーナ＆全キャラコンギミック版）

Three.js を使った FPS視点の3Dパルクール鬼ごっこです。
マップを 140×140 に大幅拡張し、空中ダッシュ・グラップルワイヤー・ジップライン・スピードブースト床を追加しました。

## 新機能（v5）
- **広大アリーナ（140×140）**：3段構成の中央メガタワー、4隅のスカイタワー、連続ウォールラン壁、浮島、グラップル用の高い柱、スライディングゲート、13個のジャンプパッド、6枚のスピードブースト床を配置。
- **キャラコン装備（ギミック選択）**：スタート・一時停止画面から以下を切り替えられます。
  - **全部盛り**（空中ダッシュ＋ワイヤー＋ジップライン）
  - **空中ダッシュ**（DASH＋ZIP）
  - **ワイヤー機動**（WIRE＋ZIP）
  - **クラシック**（基本パルクールのみ）
- **空中ダッシュ（DASH / Q）**：向いている方向へ一気に急加速・急旋回。
- **グラップリングワイヤー（WIRE / 右クリック or F）**：中央の照準が水色に光った壁や柱にワイヤーを撃って高速移動。途中でジャンプするとスリングショットで大きく飛べます。
- **ジップライン（ZIP / E）**：高台同士をつなぐ黄色のケーブルに近づいて乗車。ミニマップにも黄色い線で表示されます。
- **全ボタン配置カスタマイズ**：`JUMP` / `SLIDE` / `DASH` / `WIRE` / `ZIP` / 左スティックをすべてドラッグで好きな位置に配置・保存できます。

## GitHub Pages で公開する手順
1. GitHub リポジトリにこのZIPの中身（`index.html`, `style.css`, `game.js`, `README.md`）を直下に配置します。
2. リポジトリの **Settings** → **Pages** → **Branch** を `main`（`/ (root)`）にして **Save** を押します。
3. 発行されたURLをiPadやスマホ、PCのブラウザで開いてプレイしてください。

## v5 追加機能
- **カメラ感度調整スライダー**：スタート画面・一時停止画面から視点移動の速さを `0.2x`〜`3.0x` の範囲で変更できます（PCマウス・スマホ/iPadタッチの両方に対応、設定は自動保存されます）。
